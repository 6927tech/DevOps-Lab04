# DevOps-Lab04

## เกี่ยวกับโปรเจกต์

โปรเจกต์นี้เป็นหน้าเว็บไซต์ตัวอย่างสำหรับ **IT Support Service Center** ใช้เป็นช่องทางให้พนักงานดูบริการช่วยเหลือด้านไอทีและแจ้งปัญหาอุปกรณ์หรือระบบต่าง ๆ โดยหน้าเว็บและเนื้อหาแสดงผลเป็นภาษาไทย

## ฟีเจอร์

- แสดงบริการช่วยเหลือด้านคอมพิวเตอร์ เครือข่าย เครื่องพิมพ์ และการจัดการสิทธิ์ผู้ใช้
- อธิบายขั้นตอนการแจ้งปัญหา ตั้งแต่รับเรื่องจนถึงปิดเคส
- มีแบบฟอร์มตัวอย่างสำหรับกรอกชื่อผู้แจ้ง ประเภทปัญหา และรายละเอียด
- แสดงข้อมูลติดต่อของศูนย์ช่วยเหลือ
- ออกแบบให้รองรับหน้าจอหลายขนาด

## เทคโนโลยี

- HTML
- CSS ที่ฝังอยู่ภายในไฟล์หน้าเว็บ

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้งแพ็กเกจหรือเริ่มเซิร์ฟเวอร์

## หมายเหตุ

โปรเจกต์นี้เป็นหน้าเว็บส่วนติดต่อผู้ใช้ตัวอย่างเท่านั้น แบบฟอร์มยังไม่ได้เชื่อมต่อกับระบบหลังบ้าน จึงยังไม่บันทึกหรือส่งข้อมูลแจ้งซ่อมจริง
